# Job Postings Summarizer

A utility to process and summarize job posting data from JSON files.

## Core Rules & Constraints

- **Filtering:** Always filter out roles with less than 3 years of experience required.
- **Data Normalization:** Handle inconsistent field names like `experience_required` vs `years_of_experience`.
- **Extraction:** Scan job descriptions for defined technology keywords.
- **Categorization:** Group results by the job location.

## Workflow Steps

1. **Locate Data:** Identify the target JSON file in the user's workspace.
2. **Execute Script:** Run the bundled `skills/job-postings-summarizer/scripts/summarize.py` script using the `run_code` tool, passing the path of the JSON file as an argument.
3. **Present Summary:** Provide the output generated by the script, which is formatted with locations as headers and bulleted lists of tech keywords.

## Output Specifications

The script produces output in the following format:

### <Location>
- <Keyword>
- <Keyword>

## Scripts

- `skills/job-postings-summarizer/scripts/summarize.py`: Performs the filtering, keyword extraction, and grouping logic.
